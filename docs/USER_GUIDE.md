# Fun City Arcade — macOS Help

Your personal 1980s-inspired Mac arcade

## How to play

Choose one of the seven cabinets on the arcade floor. Select a cabinet to see its installation state, Play Now, and the download or update command. Our Story preserves the real inspiration behind the collection.

## Keyboard and mouse controls

| Control | Action |
|---|---|
| Select a cabinet | Click a game tile in the Arcade Floor. |
| Play Now | Launch the installed application. |
| Download / Update | Fetch a signed game release and install it locally. |
| High Scores | Show local personal bests from installed games. |
| Our Story | Read the complete origin story; optional ambience is off by default. |

## Scores, saves and settings

Each game stores its own scores, settings, and saved games. Fun City records library links locally. Launcher updates use Sparkle only in signed distribution builds; Xcode Debug builds use Git.

## Application menus

The native **Game** menu offers How to Play, Controls & Shortcuts, and Scores & Saving. The **Help** menu opens these offline instructions. Standard macOS App, Edit, Window, and Quit commands remain provided by the operating system. In-game gameplay buttons and shortcuts are unchanged.
